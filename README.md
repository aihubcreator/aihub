# AIHub — Платформа для внедрения ИИ

## 🚀 О проекте

AIHub — это платформа, которая соединяет бизнес со студентами-практиками для бесплатного внедрения искусственного интеллекта.

### Для бизнеса
- Бесплатное внедрение ИИ
- Готовый MVP или прототип
- Студенты под руководством наставников

### Для студентов
- Реальные проекты для диплома
- Опыт внедрения ИИ
- Портфолио для резюме

## 🛠️ Технологии

- HTML5 / CSS3 / JavaScript
- Telegram Bot API
- localStorage

## 📦 Установка

1. Скачайте репозиторий
2. Создайте файл `config.js` с вашими токенами
3. Откройте `index.html` в браузере
