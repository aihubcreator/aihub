📋 Политика обработки персональных данных

1. Общие положения

Настоящая политика обработки персональных данных составлена в соответствии с требованиями Федерального закона от 27.07.2006 № 152-ФЗ «О персональных данных».

2. Какие данные мы собираем

  • ФИО и контактные данные (email, телефон);
  • Название компании и сфера деятельности;
  • Описание задачи для автоматизации;
  • Бюджет проекта (по желанию).

3. Цели обработки данных

  • Подбор студента для вашего проекта;
  • Связь с вами для уточнения деталей;
  • Информирование о статусе заявки.

4. Сроки обработки

Данные хранятся до завершения проекта, но не более 3 лет.
